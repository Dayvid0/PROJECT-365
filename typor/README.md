# Typing Automator Chrome Extension

A powerful typing automation tool for Chrome that simulates human-like typing on any webpage with customizable speed control and DOCX import support.

## Features

- ⌨️ **Automated Typing**: Types text character-by-character with human-like speed
- 🎚️ **Speed Control**: Adjustable typing speed from 0.5x to 10x
- 📄 **DOCX Import**: Import text directly from Word documents
- 🔒 **Activation System**: Secure licensing with trial mode
- 🎯 **Universal Compatibility**: Works on any text field, textarea, or contenteditable element
- 🌐 **Works Everywhere**: Gmail, Google Docs, forms, chat apps, and more
- 🧹 **Text Cleaning**: Automatically removes formatting issues
- 💾 **Auto-Save**: Remembers your text between sessions

## Installation

### Method 1: Developer Mode (Recommended for Testing)

1. **Download the Extension**
   - Ensure all files are in the `typing_automator_extension` folder

2. **Open Chrome Extensions Page**
   - Open Chrome browser
   - Navigate to `chrome://extensions/`
   - Or click menu (⋮) → More Tools → Extensions

3. **Enable Developer Mode**
   - Toggle the "Developer mode" switch in the top-right corner

4. **Load the Extension**
   - Click "Load unpacked"
   - Select the `typing_automator_extension` folder
   - The extension will appear in your extensions list

5. **Pin the Extension**
   - Click the puzzle piece icon (🧩) in Chrome toolbar
   - Find "Typing Automator"
   - Click the pin icon to keep it visible

## Usage

### Basic Usage

1. **Click the Extension Icon**
   - Opens the Typing Automator popup

2. **Enter or Import Text**
   - Type/paste text directly in the text area
   - Or click "Import DOCX" to load a Word document

3. **Adjust Speed** (Optional)
   - Use the slider to set typing speed
   - 1.0x = Normal speed
   - 0.5x = Very slow
   - 10x = Maximum speed

4. **Start Typing**
   - Click "Start Typing" button
   - Click on any text field on the webpage
   - Watch as the text is typed automatically

5. **Stop Typing** (if needed)
   - Click the "Stop" button in the popup
   - Or click the stop button in the on-screen indicator

## Troubleshooting

**Extension Not Working?**
- Refresh the webpage after installing
- Make sure the website allows extensions
- Check if the text field is editable

**Typing Not Starting?**
- Click directly on the text field
- Ensure the field has focus
- Try clicking the field again

**DOCX Import Issues?**
- Only .docx files are supported
- File must be valid Word document
- Try re-saving the document
